# 在 Codex 里使用牙签

Codex 会读取项目根目录的 `AGENTS.md`。把下面这段复制到你项目的 `AGENTS.md` 里，并把路径改成 skill 文件夹实际所在的位置。

```markdown
## 界面设计

做任何设计或修改用户界面的任务前（网页、落地页、后台、桌面或移动 App、组件、样式、配色、深色模式、README 或图表）：

1. 先阅读 `skills/toothpick-zh-CN/SKILL.md`，按其中的流程执行。
2. 根据界面类型阅读 `skills/toothpick-zh-CN/references/` 下对应的文件。
3. 交付前对照 `skills/toothpick-zh-CN/checklist.md` 自检，并在回复里附上占位清单。
```

英文版请改用 `skills/toothpick/`。
