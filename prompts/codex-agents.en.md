# Using Toothpick with Codex

Codex reads `AGENTS.md` in the project root. Copy the block below into your project's `AGENTS.md`, and change the path to wherever you put the skill folder.

```markdown
## UI design

Before any task that designs or changes a user interface (web pages, landing pages, admin panels, desktop or mobile apps, components, styling, color, dark mode, READMEs or diagrams):

1. Read `skills/toothpick/SKILL.md` and follow its workflow.
2. Read the matching files in `skills/toothpick/references/` for the kind of interface.
3. Before delivering, review the result against `skills/toothpick/checklist.md`, and attach the placeholder list to your reply.
```

For Chinese, use `skills/toothpick-zh-CN/` instead.
