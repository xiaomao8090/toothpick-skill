# 软件 / 后台 / 桌面端

适用：SaaS 应用、管理后台、仪表盘、编辑器、桌面客户端、内部工具。

软件界面的目标是**让人每天用几个小时也不累，并且越用越快**。它不需要第一眼惊艳，需要的是清楚、稳定、高效。AI 最常犯的错就是把它做成营销页。

下面的数值是常见做法的参照（GitHub、ChatGPT 的实测见 `benchmarks.md`），不是硬性要求，按产品需要调整。

## 信息密度

- 常见密度：正文 13–14px，表格行高 32–41px，表单控件高 32–36px（GitHub 仓库页：14px 正文、41px 行高、32px 按钮）。
- 留白用来分组，不是用来"显得高级"。一屏能看到的有效信息越多越好（在不拥挤的前提下）。
- 可以考虑提供密度切换（紧凑 / 舒适），尤其是表格多的产品。

## 布局

- 经典结构：左侧导航（可折叠）+ 顶部工具栏/面包屑 + 主内容区，必要时右侧详情面板。
- 页面标题区要矮：标题 + 主要操作按钮放一行，不要大标题加大段说明。
- 删掉"欢迎回来，XXX！👋"这类问候横幅。
- 主内容区占满宽度（表格类）或限制宽度（表单/设置类，约 640~800px）。

## 表格（后台的核心）

- 文字左对齐，**数字右对齐**并用等宽数字（`tabular-nums`），这样小数点能对齐。
- 表头字号略小、颜色略浅，可以全大写（英文）或加粗，固定在顶部。
- 行之间用细分隔线或斑马纹二选一，不要两个都用。
- 悬停行高亮；选中行用强调色的极浅版本。
- 支持排序（表头显示排序状态）、必要的筛选、分页或虚拟滚动。
- 超长文本截断加省略号，悬停显示完整内容。
- 操作列：常用操作 1~2 个直接显示（或悬停显示），其余收进"更多"菜单。
- 空表格要有空状态说明和下一步操作。

## 表单

- 标签放在输入框上方（最易扫读），不要只用 placeholder 当标签。
- 相关字段分组，组之间留更大间距或用小标题。
- 必填/选填只标少的那一种。
- 校验：失去焦点时校验，错误信息写在字段下方，说清楚怎么改（❌"格式错误" ✅"手机号应为 11 位数字"）。
- 主按钮放在表单末尾，与阅读方向一致；危险操作（删除）和主操作分开放，并且需要二次确认。

## 状态（必须全部设计）

| 状态 | 要做什么 |
|---|---|
| 加载中 | 用骨架屏保持布局不跳；超过 300ms 才显示加载提示 |
| 空状态 | 说明为什么是空的 + 一个下一步操作按钮；首次使用和"筛选无结果"是两种不同的空状态 |
| 出错 | 说清楚发生了什么、用户能做什么（重试/联系谁），不要只显示错误代码 |
| 无权限 | 说明需要什么权限、找谁申请 |
| 部分数据 | 有的字段为空时显示"—"，不要显示 null、undefined 或空白 |
| 操作反馈 | 保存成功用轻量提示（toast 2~4 秒自动消失）；耗时操作显示进度 |

## 仪表盘

- 先问：用户每天打开这个页面要**做什么决定**？只放支持这个决定的信息。
- 每个数字都要有上下文：和什么比（上周？目标？）、是好是坏。
- 不要四张一模一样的统计卡片排一排。关键指标可以更大，次要指标可以更小、更紧凑。
- 图表选择：趋势用折线，比较用条形，占比少用饼图（超过 5 类不要用饼图）。图表配色用灰阶 + 1~2 个重点色，不要彩虹色。
- 需要画图表时，图表标题直接写结论（"本周退款率比上周高 2%"），而不是"退款率趋势图"。

## 交互与效率

- **键盘**：常用操作有快捷键，在按钮的提示气泡或菜单里显示快捷键；支持 Tab 顺序合理、Esc 关闭弹窗、Enter 提交。
- 考虑命令面板（Ctrl/⌘ + K），适合功能多的产品。
- 批量操作：多选后在顶部或底部出现批量操作栏。
- 能撤销的操作不要弹确认框，用"已删除 · 撤销"的提示代替；不能撤销的才二次确认。
- 记住用户的选择：筛选条件、排序、列宽、侧栏折叠状态。
- 动效极少：只给展开/收起、出现/消失加 100~200ms 的过渡。

## 桌面客户端额外注意

- 遵循所在平台的习惯：macOS 窗口按钮在左、菜单在系统顶栏；Windows 按钮在右。
- 跟随系统明暗设置和系统强调色（如果框架支持）。
- macOS 不要把关键控件放在窗口最底部（用户常把窗口拖到屏幕外一截）。
- 窗口缩小到最小尺寸时布局仍然可用；设置最小窗口尺寸。
- 右键菜单要有，并且和顶部菜单里的操作一致。
- 文字默认 13px（macOS 系统默认），Windows 默认 14px 左右。

## 导航

- 左侧导航一级不超过 7~9 项，多了就分组（加小标题）。
- 当前位置清晰：导航高亮 + 面包屑（层级深时）。
- 图标 + 文字；折叠后只剩图标时，悬停显示文字。
