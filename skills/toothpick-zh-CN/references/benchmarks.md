# 大厂产品实测参照

> 2026 年 10 月在浏览器里读取的实际样式（1440px 宽）。
> **这是参照，不是标准。** 这些都是科技产品，咖啡店、建筑事务所照抄它们的样子同样是错的。
> 要学的是背后的做法：克制、精确、一致、让产品本身当主角。

## 各站数据

### Vercel 官网
- 背景 #FAFAFA，面板白色；正文 #171717，次要文字 #4D4D4D（纯中性灰）
- 一套字体 Geist，等宽 Geist Mono 只出现在代码和产品示意里
- 标题 48–64px，**字重 400–450**（不是粗体），字距约 -0.06em，行高约 1.17
- 大部分文字 14px 和 18px
- 按钮高 40px；主按钮近黑底白字，次按钮白底；圆角是全圆或 8px
- **整页几乎没有边框和分隔线**（只有 4 个元素有 border）。面板靠 `0 0 0 1px rgba(0,0,0,.08)` 的细环加一层 2px 的极淡投影
- 面板圆角以 6px 为主
- 一个区块约占 850px 高，留白很多
- 蓝色 #0072F5 基本只用在链接上
- 产品画面（图片、代码示意、界面示意）约占页面面积 29%

### GitHub 官网
- 深色 #0D1117；字体 Mona Sans + Mona Sans Mono
- H1 64px / 字重 425，H2 40px / 460，居中
- 主按钮绿色 #08872B，圆角 6px，高 48px
- 产品画面约占页面面积 46%
- 内容最大宽度 1280px

### GitHub 仓库页（产品界面）
- 白底；正文 14px / 行高 21px，颜色 #1F2328；次要 #59636E；链接 #0969DA
- 边框用得很多（250+ 个元素），但都是浅灰 #D1D9E0，并且组成带 6px 圆角的框
- 文件列表行高 41px；小按钮 28px 高、12px 字；普通按钮 32px 高
- 这说明：**线条本身没问题，问题是线的颜色、粗细和用法**。产品界面里的浅灰框线是在组织信息，不是装饰

### ChatGPT 首页（产品界面）
- 背景 #FCFCFC，文字 #0D0D0D，次要 #5D5D5D；系统字体
- 整页可见文字只有约 20 处，极度克制
- 全页只有 1 个阴影，在输入框上：`0 0 0 1px rgba(0,0,0,.04), 0 2px 8px rgba(0,0,0,.04), 0 4px 80px 8px rgba(0,0,0,.024)`
- 输入框 768×52px，圆角 28px
- 侧栏菜单项高 36px，圆角 10px，平时透明，悬停才出现底色
- 登录按钮 44px 高，全圆角黑底

### Google 首页
- 白底，Arial / Google Sans
- 搜索框 584×52px，圆角 26px
- 按钮 36px 高、圆角 8px、浅灰底 #F8F9FA
- 登录按钮蓝色 #0B57D0、全圆角
- 整页只有 2 个阴影，都极淡

### Linear 官网
- 底色 #08090A，文字 #F7F8F8，次要 #8A8F98 / #62666D
- Inter Variable + Berkeley Mono
- H1 64px / 字重 510 / 字距 -0.022em / 行高 1.0；H2 48px / 510，左对齐
- 每个区块约 1240px 高
- 页面上大量 12–14px 的文字其实是**用 HTML 画出来的产品界面**，这是它好看的主要原因
- 圆角 8px / 12px；分隔用低透明度的白色

## 共同点

1. **颜色几乎只有黑、白、灰**，再加一个功能色（链接或主按钮）。灰色基本是纯中性或极轻的冷灰。
2. **一套字体就够**，等宽字体只用在代码和产品示意里，不用来营造"技术感"。
3. **标题大但不粗**（字重 400–510），字距收紧。冲击力来自尺寸和留白。
4. **正文 14–16px**，产品界面以 14px 为主。
5. **分隔手段很轻**：浅色 1px 细环或边框、极淡的阴影、6–12px 圆角。没有一家用黑色通栏细线来切分页面。
6. **产品本身是主角**：营销页 25–46% 的面积是产品画面。
7. **每屏只有一个重点**，没有装饰性符号、编号、小标签。
8. **没有"风格"**：它们不是"某某风"。辨识度来自产品、内容和做工的精度。

## 怎么用这份参照

- 做科技产品、工具、SaaS 时，可以直接参考这些数值的量级。
- 做其他行业时，学的是"克制、精确、一致、内容为主角"这几条，具体的颜色字体要从这个行业本身的东西里来。
- 拿不准时，用这些数值做自检：我的标题是不是太粗？颜色是不是太多？线是不是太黑太多？装饰是不是比内容还多？
