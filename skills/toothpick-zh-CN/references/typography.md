# 排版

排版决定了页面的气质。选字体要像选品牌色一样认真，而不是每个项目都用同一款。

## 原则

- **一套字体通常就够**。大厂几乎都只用一个字体家族（Vercel 用 Geist，GitHub 用 Mona Sans，Linear 用 Inter），靠字号和字重拉开层级。用两款时，要让它们明显不同，而不是两款相似的无衬线。
- **字体要为这个项目选**。先想这个产品属于什么世界：报刊、工具、儿童、金融、手工……再找属于那个世界的字体。不要每次都拿同一个"安全选择"。
- **标题大，但不一定要粗**。大厂标题普遍是字重 400–510，冲击力来自尺寸、字距和留白。到处加粗反而显得笨重。
- **大标题收紧字距**，字号越大收得越多（参照：Vercel 约 -0.06em，Linear 约 -0.022em）。正文不收。中文一般不需要负字距。
- **字号档位要少**，一个页面五六档就够。层级不清楚时，先试着减少档位、拉大差距，而不是再加一档。
- **行长控制在 80 个字符以内**（中文约 35–40 字）。衬线正文可以稍长，但行高要更大。
- **行高**：英文正文约 1.5；中文字形饱满，正文 1.7–1.8 更舒服；大标题 1.0–1.2。
- **数字对齐**：表格、价格、计时用 `font-variant-numeric: tabular-nums`。
- **标点**：中文用全角标点；英文用弯引号 “ ”。

## 常见问题

- 全大写小标签到处都是 → 见 `ai-tells.md`
- 一个页面混了三四种字体 → 通常是没有想清楚各自的角色
- 细字重用在小字上 → 看不清（苹果规范建议避免 Ultralight / Thin / Light）
- 中文用斜体 → 中文字体没有真斜体，浏览器硬拉斜很难看，用加粗或颜色强调
- 等宽字体用来营造"技术感" → 等宽字体是给代码和需要对齐的内容用的

## 中文字体的技术注意事项

- 中文网页字体很大（一个字重常常几 MB）：
  - 工具类界面直接用系统字体栈最稳：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
  - Google Fonts 的 Noto Sans SC / Noto Serif SC 会自动按需切片加载
  - 标题用特色中文字体时，只加载用到的字（子集化）
- 英文字体写在前面、中文字体写在后面：英文和数字用英文字体，汉字回落到中文字体。
- 宋体在 Windows 小字号下容易发虚，正文慎用。
- 中英文、中文与数字之间留空隙，读起来更舒服。
